# Curriculum Crew prototypes

Clickable HTML prototypes for Rumi's curriculum feature. Each is a single self-contained page.

| Page | What it is |
|---|---|
| [index.html](https://atayyub2.github.io/curriculum-crew/) | The Curriculum Crew "about us" page: the eight agents as ID cards |
| [wireframe.html](https://atayyub2.github.io/curriculum-crew/wireframe.html) | Grey-box wireframe of the first-time user flow (upload, sign up, confirm contents, timetable, difficulty, first lesson, review, unlock) |
| [onboarding.html](https://atayyub2.github.io/curriculum-crew/onboarding.html) | Visual pass of the same flow: Rumi colours and logo, landing intro animation, Square as the host, chat |
| [studios.html](https://atayyub2.github.io/curriculum-crew/studios.html) | Crew Studios: group-poster landing with upload, then the eight isometric rooms working through the book, with the must-ask questions on the left |

Prototype only: no real uploads, payments or accounts.
